# explorer-backend

Feathers explorer backend (indexer + API). Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/explorer-backend-archive`.

AWS account ids use `CDK_DEV_ACCOUNT`. p2pify RPCs were replaced with public seeds. Sentry DSN moved to `SENTRY_DSN`.

No contract deployments recorded in this repo.

## What was Built

Euler Tools' blockchain explorer backend service. Powered the indexer, API layer, and data pipeline that served blockchain data to the explorer frontend.

## Qué se Construyó

Servicio backend del explorador blockchain de Euler Tools. Impulsó el indexador, la capa de API y el pipeline de datos que sirvieron los datos blockchain al frontend del explorador.
